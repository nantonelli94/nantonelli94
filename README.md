## 👨‍🔬 About Me

I am a **Marine Engineer** (Ingeniero Naval) from UTN FRMDP with a strong focus on **ship resistance, marine propulsion, and computational fluid dynamics (CFD)**. Currently, I serve as **Professor and Researcher at UTN FRMDP** while pursuing a **PhD in Engineering** at UNMDP FI with a CONICET fellowship.

My work spans from academic research in hydrodynamic optimization to applied engineering consultancy for the marine industry. I develop **open-source educational tools** using Python and Streamlit to teach naval architecture concepts interactively.

**Contact:** 📧 nicolasantonelli50@gmail.com | 📍 Mar del Plata, Argentina

## 🚀 Open-Source Projects

### Computational Fluid Dynamics
| Repository | Description |
|:-----------|:------------|
| [**hydrofoil-overset**](https://github.com/nantonelli94/hydrofoil-overset) | Automated 2D OpenFOAM overset CFD case generation for NACA hydrofoils with prescribed motion. Gmsh mesh, dynamic mesh setup, and postprocessing from a single YAML config. |

### Propulsion & Ship Design
| Repository | Description |
|:-----------|:------------|
| [**prop3d**](https://github.com/nantonelli94/prop3d) | Interactive 3D parametric propeller generator (Wageningen B & Kaplan Ka series) for naval architecture education. |
| [**propy_opt**](https://github.com/nantonelli94/propy_opt) | Analytical marine propeller design & optimization using Wageningen B series with Keller cavitation verification. |
| [**propulse**](https://github.com/nantonelli94/propulse) | Conceptual ship resistance & power prediction tool — open-source web app. |
| [**ship-resistance-game**](https://github.com/nantonelli94/ship-resistance-game) | Educational simulation game: learn longitudinal ship strength by distributing cargo and ballast with Euler-Bernoulli beam physics. |

### Mechanics & Education
| Repository | Description |
|:-----------|:------------|
| [**lagrangianmechanics**](https://github.com/nantonelli94/lagrangianmechanics) | Interactive Lagrangian mechanics simulator: derive equations of motion, integrate numerically, and visualize phase-space orbits. |
| [**mec-rac**](https://github.com/nantonelli94/mec-rac) | Interactive digital textbook for Rational Mechanics with theory, solved problems, and dynamic simulations. |
